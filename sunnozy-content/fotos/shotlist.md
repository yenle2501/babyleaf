# Foto-Shotlist

**Equipment (reicht):** Smartphone (Portrait-/Hauptkamera, kein Ultraweitwinkel), Stativ mit Top-down-Arm, weisser Reflektor (oder Styroporplatte), Fenster mit Tageslicht.
**Setup:** Fenster seitlich, gegenüber Reflektor aufhellen. Bester Zeitraum: Vormittag oder bewölkter Tag.
**Formate:** jeweils **4:5** (Feed), **9:16** (Stories) und **1:1** (Shop/Etsy/ricardo) einplanen, also mit Rand fotografieren.

## Block A – Shop- & Produktfotos (pro Set)
| # | Motiv | Hinweis |
|---|---|---|
| A1 | Komplettes Set als Flatlay auf Creme/Leinen | Top-down, symmetrisch, etwas Luft drumherum |
| A2 | Set gefaltet und gestapelt | 45°-Winkel, Holzbrett darunter |
| A3 | Jedes Teil einzeln, Vorder- & Rückseite | Für Shop-Galerie |
| A4 | Detail: Druckknöpfe, Nähte, Etikett „100 % Baumwolle“ | Makro / 2×-Zoom |
| A5 | Stoff-Struktur im Gegenlicht | Zeigt Musselin-Qualität |
| A6 | Set im Weidenkorb mit Trockenblumen | Lifestyle-Variante |
| A7 | Grössenvergleich Body neben Hand / Lineal | Hilft Kaufentscheidung |

## Bearbeitung
- Einheitlicher Look: leicht warm (+5 Temperatur), Kontrast -10, Schatten +15, Sättigung -5
- In Lightroom Mobile als **Preset „sunnozy warm“** speichern und auf alle Fotos anwenden
- Shop-Fotos: Hintergrund gleichmässig Creme, keine Filter auf Produktfarben (Farbtreue!)
