# Reels Weihnachts-Geschenkboxen: schlafendes Baby (04.11.2026)

Im gleichen Stil wie die Reels, die gut liefen: schlafendes Baby, ruhig, langsamer Zoom, kurzer POV-Text ab Sekunde 0. Danach die Box mit Inhalt, zum Schluss Preis und **Link direkt auf diese eine Box** (nicht auf die Kollektion).

Erstellt mit `python3 tools/make_reels_box_schlaf.py [box]`. 9:16, 1080 × 1920, ca. 13 s, mit Musik (Alex Morgan, Pixabay, frei nutzbar), Loop zurück ins erste Bild, `_titelbild.jpg` als Cover.

**Babybilder** (`baby/`): KI (Canva), frei erfundene Babys. Die Box-Flatlays dienten nur als Vorlage für die Kleidung, keine Fotos fremder Babys. Safe Sleep: Rückenlage, feste flache Matratze mit glattem Spannleintuch, nichts im Bettchen (keine Decke, kein Kissen, kein Plüschtier, keine Mütze, kein Haarband).
