# Reels: Weihnachts-Geschenkboxen

Erstellt mit `python3 tools/make_reels_weihnachtsbox.py` aus den Szenen im Handyfoto-Stil (`../fotos-echt/`) und den Box-Fotos von oben (`../fotos/`). Langsamer Zoom, Schnitte, Text ab Sekunde 0 (Cormorant Garamond wie die Baby-Reels), Musik von Alex Morgan (Pixabay, `posts/reels/musik/`), Schlusskarte und Loop ins erste Bild. Jeweils mit `_titelbild.jpg`.
