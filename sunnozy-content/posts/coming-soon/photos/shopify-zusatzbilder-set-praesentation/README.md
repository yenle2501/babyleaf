# Shopify-Zusatzbilder für die Sets aus der Set-Präsentation (Einzelteile und Nahaufnahmen)

Gleicher Stil wie `../shopify-zusatzbilder-coming-soon/`: warmer, heller Studio-Grund, grosse Teile am Holzbügel mit Wandknauf, kleine Teile flach gelegt. 2048 × 2048 px, ohne Logo.

Pro Set ein Ordner mit jedem Teil einzeln (`strampler.jpg`, `body.jpg`, `muetze.jpg` …) und Nahaufnahmen von Stoff, Print oder Stickerei (`nah_*.jpg`).

**So entstanden:** Gemini (Bildgenerierung) mit drei Bildern: das Set-Bild aus `../produktfotos-set-praesentation/ki-roh/set_<set>_quadratisch.jpg` als Vorlage für die Teile, dazu `strampler.jpg` (Little Bear) und `body.jpg` (Waldbär) aus `../shopify-zusatzbilder-coming-soon/` als Stilvorlage. Gemini liefert 1024 px; hochgerechnet mit Real-ESRGAN x2 auf 2048 px, 25 % Lanczos zurückgemischt, leicht geschärft. ChatGPT war am 17.11. am Limit.
