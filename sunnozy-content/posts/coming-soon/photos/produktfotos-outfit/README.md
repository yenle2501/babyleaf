# Outfit-Produktfotos (Stil wie childom.ru)

Jedes Outfit liegt einzeln von oben, als würde ein Baby es tragen: Body oben, Hose darunter, Häubchen oder Söckchen dazu.
Warmer Creme-Beige-Hintergrund, viel Freiraum, weiches Licht, Stoffe glatt ohne Falten.

Mit KI neu erstellt (Canva). Vorlagen waren deine echten Produktfotos, das echte sunnozy-Spitzen-Häubchen und die Söckchen sowie dein Beispielbild als Stil.

**Tipp:** Als Karussell posten (1–5) oder einzeln im Raster zwischen die Handschrift-Posts.

**Bitte prüfen:**
- Das Häubchen ist auf den Bildern feiner gerippt als euer echtes
- Die Söckchen haben kleine Rüschen
- Das Blumenmuster ist etwas kleiner als beim echten Produkt
