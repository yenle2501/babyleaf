# Studio-Look aus Handyfotos

Generator: `tools/make_studio.py` (Freisteller: Canva „Hintergrund entfernen“).

**Was gemacht wurde:**
- Kleider freigestellt: Tisch, Boden, Tüte und Sticker sind weg
- Weissabgleich (gelb-grüner Zimmerlicht-Stich entfernt), Belichtung heller, leicht geschärft
- Studio-Hintergrund mit sanftem Lichtverlauf und weichem Schatten unter den Kleidern
- Kleider, Farben, Prints und Etiketten sind **echt**, nichts ist KI-generiert

| Ordner | Format | Wofür |
|---|---|---|
| `studio/` | 1080×1350, warmweiss | Instagram-Feed |
| `shop/` | 1600×2000, reinweiss | Webshop / Produktseite |
| `farbig/` | 1080×1350, rosa / lila / salbei | Instagram, Abwechslung im Raster |
| `freigestellt/` | PNG transparent | eigene Designs in Canva |
| `original/` | – | deine Originalfotos |

Bilder 02 und 03 sind fast gleich, weil die beiden Originalfotos sehr ähnlich waren. Nimm das, das dir besser gefällt.

**Tipps fürs nächste Handy-Shooting:**
- Bei Tageslicht am Fenster fotografieren, Deckenlicht aus
- Von oben, Handy parallel zum Tisch
- Etwas Abstand lassen, damit nichts am Bildrand abgeschnitten wird
- Kleider vorher glatt streichen
