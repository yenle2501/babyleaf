# Stilvorlagen Baby-Fotos (Handyfoto, Pinterest-Stil)

Deine früher geschickten Vorlagen: Babys von oben mit dem Handy fotografiert, auf zerknittertem weissem Laken oder Strickdecke, Tageslicht, kein Studio-Look. Sie dienen als Stilvorlage für die KI-Baby-Fotos (in Canva als zweites Referenzbild, z.B. `referenz_11.jpg` für weisses Laken und `referenz_06.jpg` für Strickdecke).

Nur als Vorlage verwenden, nicht posten (fremde Fotos).
